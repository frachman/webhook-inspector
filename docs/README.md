# Hookbin documentation

Hookbin is Mikrolyt M01: a disposable webhook endpoint for debugging what an
application sends. The public journey is:

1. Create an endpoint.
2. Send a webhook.
3. Inspect the captured request.

Use test or non-sensitive data. Endpoints and captured requests are temporary.
